## 3. Recommended Unified Token Specification

### 3.1 Color Palette Standardization
- **Brand Primary (Deep Operational Navy)**: `#0F3B6C` (`AppColors.primaryDark`) / `#1E3A5F` (`AppColors.primary`)
- **Interactive Accent (Action Blue)**: `#1B64F2` / `#2563EB` (`AppColors.accent`)
- **Canvas Background**: `#F4F7FB` (`AppColors.background`)
- **Card / Surface**: `#FFFFFF` (`AppColors.surface`) with `1px` border `#E2E8F0` (`AppColors.border`)
- **Semantic Statuses**:
  - **Critical / High Severity / Offline / Error**: `#DC2626` text/icon on `#FEE2E2` surface (`#FECACA` border)
  - **Warning / Medium Severity / Stopped / Disconnected**: `#D97706` text/icon on `#FEF3C7` surface (`#FDE68A` border)
  - **Active / In Progress / Assigned**: `#2563EB` text/icon on `#DBEAFE` surface (`#BFDBFE` border)
  - **Resolved / Safe / Moving / Completed**: `#059669` text/icon on `#D1FAE5` surface (`#A7F3D0` border)

### 3.2 Typography Scale (`Cairo`)
- **Page Title (Desktop)**: `20px`, `FontWeight.w800`, `#0F172A`
- **Page Title (Mobile)**: `18px`, `FontWeight.w800`, `#FFFFFF` (on navy header) or `#0F172A` (on white AppBar)
- **Section / Card Header**: `15px–16px`, `FontWeight.w700`, `#0F172A`
- **Body / Table Cell / Input Text**: `13.5px–14px`, `FontWeight.w600`, `#1E293B`
- **Secondary Metadata / Badges / Timestamps**: `12px` minimum (`FontWeight.w600`), `#475569` (never below `11.5px` for Arabic script)
